# L4 0.1.0-alpha.1

First developer alpha from a fresh repository and release history. The prototype is archived separately; this release is for fresh databases and does not upgrade prototype installations.

L4 is MIT licensed software for independent communities. An Instance owns local Accounts and a directory of isolated Servers. Each Server owns membership, Roles, conversations and content. Mail, Agents, Tasks, Data and Apps are capabilities inside a Server.

- One initial SQL migration each for Server, Instance and installer databases. Public server UUIDs and the provisioning refresh lease are present from the Instance baseline.
- Historical migration fixtures and prototype release notes are excluded. Current tests use the shipped fresh schemas.
- Live storage uses current names; retired scheduled huddles and voice-channel schema compatibility are removed.
- The interface uses Server and Instance, separates creation from advanced registration, and includes a screenshot preview with an optional sandbox link.
- Releases require explicit tagging after CI. Site deployment is disabled until the operator configures it; a source push does not authorize applying fresh baselines to an old database.

Cloudflare is the first acceptance target. VPS/celld is experimental: proxy WebSocket, persisted server selection and SPA deep-link behavior need runtime/browser acceptance as recorded in the roadmap. The sandbox link is not an anonymous read-only demo. Native iOS/macOS distribution remains frozen. Optional email, inference and media Providers need independent configuration and verification.

See the release validation record in `docs/bootstrap-validation.md` for checks performed on this baseline. Published artifacts are immutable; subsequent schema changes append migrations.
